SKOVHUGGER LUND - GITHUB PAGES WEBSITE - FLAT ZIP
=================================================

All files in this archive are at the root level. There are NO directories.

UPLOAD INSTRUCTIONS
1. Create a PUBLIC GitHub repository (example: skovhugger-lund).
2. Choose Add file > Upload files. Drag ALL extracted files to the repository ROOT.
   Do NOT upload the ZIP itself into the repository.
3. Commit changes.
4. Open Settings > Pages > Build and deployment > Deploy from a branch.
5. Set branch = main; folder = /(root), then Save.
6. Open the published site URL once GitHub shows it. Test every page/menu link.

PAGES
index.html    - homepage
services.html - service overview
blog.html     - learning library / educational resource index
about.html    - about the business
contact.html  - contact methods
privacy.html  - privacy information (review before publication)
styles.css    - design and responsive layout
main.js       - mobile menu and learning library filters
logo.png      - circular identity supplied for project
favicon.png   - icon
forest-hero.svg - illustrated, not a real project photograph
robots.txt    - generic crawler rules
.nojekyll     - prevent unwanted Jekyll processing

NOTES
- Articles have intentionally NOT been created: approval checkpoint first.
- Existing learning resources link to official Skovhugger Lund pages; they are NOT new articles.
- The pages deliberately omit canonical URLs and sitemap.xml until the final GitHub Pages URL is known, avoiding incorrect SEO signals.
- Add each approved article as a new flat HTML file and update blog.html links.
- The logo is a new circular design created for this package, not the original trademark file.
- No claim is made that this site has been deployed, indexed, or approved by Google.
- Verify privacy text, images, working links and details prior to deployment.
