SKOVHUGGER LUND - GITHUB PAGES WEBSITE - FLAT ZIP
=================================================

All files in this archive are at the root level. There are NO directories.

UPLOAD INSTRUCTIONS
1. Create a PUBLIC GitHub repository (example: skovhugger-lund).
2. Choose Add file > Upload files. Drag ALL extracted files to the repository ROOT.
   Do NOT upload the ZIP itself into the repository.
3. Commit changes.
4. Open Settings > Pages > Build and deployment > Deploy from a branch.
5. Set branch = main; folder = /(root), then Save.
6. Open the published site URL once GitHub shows it. Test every page/menu link.
